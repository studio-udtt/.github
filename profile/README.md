## 🌱 About 프로젝트 우당탕탕
### 의뢰 → 모집 → 실행 → 기록 → 확산

**프로젝트의 경험이 다음 만남으로 이어질 수 있도록.**

스튜디오 우당탕탕은 다양한 사람들과 함께 지역과 공간의 문제를 해결하는 프로젝트를 진행해 왔습니다.

하지만 프로젝트가 종료된 이후 그 과정과 경험을 공유하거나 새로운 협업으로 연결할 공간이 부족했고, 새로운 참여자와 의뢰자가 스튜디오의 활동을 쉽게 접하기 어려웠습니다.

**프로젝트 우당탕탕**은 이러한 문제를 해결하기 위해 탄생한 **지도 기반 프로젝트 아카이빙 및 협업 플랫폼**입니다.

완료된 프로젝트의 위치와 과정, 결과를 지도 위에 기록하고, 사용자는 지역별 프로젝트를 탐색하여 참여하거나 새로운 프로젝트를 의뢰할 수 있습니다.

나아가 프로젝트의 경험이 새로운 참여와 협업으로 이어지는 지속 가능한 연결을 만들어갑니다.

## ✨ Key Features

| 기능 | 설명 |
|:---|:---|
| 🗺️ **지도 기반 프로젝트 탐색** | 네이버 지도를 통해 지역별 프로젝트 위치와 진행 상태를 시각화합니다. |
| 📂 **프로젝트 아카이빙** | 프로젝트의 진행 과정과 결과를 기록하고 공유합니다. |
| 🙋 **프로젝트 참여 모집** | 모집 중인 프로젝트를 확인하고 참여 신청을 진행합니다. |
| 📝 **프로젝트 의뢰** | 프로젝트 위치, 유형, 규모 등을 입력해 새로운 프로젝트를 의뢰합니다. |
| 🔐 **관리자 통합 관리** | 프로젝트 등록, 의뢰 및 참여 신청 승인과 반려를 관리합니다. |
| 💬 **문자 알림 서비스** | 프로젝트 운영과 관련된 안내 문자를 발송합니다. |
| 📊 **콘텐츠 및 통계 관리** | 프로젝트 관련 콘텐츠와 운영 통계를 관리합니다. |
